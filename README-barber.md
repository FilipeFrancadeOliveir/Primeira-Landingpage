# ✂️ Driving Cut - Barbearia Móvel

Uma landing page moderna e inovadora para um serviço de barbearia móvel, criada para revolucionar o conceito de atendimento domiciliar no ramo da beleza masculina.

## 🚐 Sobre o Projeto

Esta landing page foi desenvolvida para o **Driving Cut**, um serviço inovador de barbearia móvel que atende clientes em Porto Sul e região. O projeto demonstra como a tecnologia pode ser aplicada para modernizar serviços tradicionais, oferecendo comodidade sem abrir mão da qualidade.

## 🔧 Personalização

### **Para Adaptar o Projeto:**

1. **Cores**: Modifique as variáveis CSS no arquivo `barber-styles.css`
2. **Conteúdo**: Edite textos e preços no `barber-landing.html`
3. **Serviços**: Adicione/remova serviços na seção correspondente
4. **Contato**: Atualize informações de contato e WhatsApp
5. **Área de Atendimento**: Modifique a região de cobertura

### **Integração com Backend:**
- Substitua a simulação do formulário por requisições reais
- Adicione validação server-side
- Implemente sistema de agendamento real
- Conecte com banco de dados
