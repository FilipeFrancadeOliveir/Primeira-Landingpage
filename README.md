# 🚀 TechSolutions - Landing Page

Uma landing page moderna e responsiva para uma empresa fictícia de desenvolvimento web, criada como projeto de portfólio.

## 📋 Sobre o Projeto

Esta é uma landing page completa desenvolvida com HTML5, CSS3 e JavaScript vanilla. O projeto demonstra habilidades em desenvolvimento front-end, incluindo design responsivo, animações CSS, interatividade JavaScript e boas práticas de desenvolvimento web.

## ✨ Características

- **Design Moderno**: Interface limpa e profissional com gradientes e efeitos visuais
- **Totalmente Responsivo**: Funciona perfeitamente em desktop, tablet e mobile
- **Animações Suaves**: Efeitos de scroll, hover e transições CSS
- **Navegação Intuitiva**: Menu hambúrguer para mobile e navegação suave
- **Formulário de Contato**: Com validação e feedback visual
- **Performance Otimizada**: Código limpo e otimizado para carregamento rápido

## 🛠️ Tecnologias Utilizadas

- **HTML5**: Estrutura semântica e acessível
- **CSS3**: Estilos modernos com Flexbox e Grid
- **JavaScript ES6+**: Interatividade e funcionalidades dinâmicas
- **Font Awesome**: Ícones vetoriais
- **Google Fonts**: Tipografia Poppins

## 📁 Estrutura do Projeto

```
Projeto-Landingpage/
├── index.html          # Página principal
├── styles.css          # Estilos CSS
├── script.js           # JavaScript
└── README.md           # Documentação
```

## 🎨 Seções da Landing Page

1. **Header**: Navegação fixa com logo e menu
2. **Hero**: Seção principal com call-to-action
3. **Serviços**: Grid de cards com os serviços oferecidos
4. **Sobre**: Informações sobre a empresa com estatísticas
5. **Contato**: Formulário de contato e informações
6. **Footer**: Links úteis e redes sociais

## 🚀 Como Executar

1. Clone ou baixe o projeto
2. Abra o arquivo `index.html` em qualquer navegador moderno
3. Ou use um servidor local (recomendado):
   ```bash
   # Com Python
   python -m http.server 8000
   
   # Com Node.js (http-server)
   npx http-server
   
   # Com Live Server (VS Code)
   # Instale a extensão Live Server e clique com botão direito no index.html
   ```

## 📱 Responsividade

A landing page é totalmente responsiva e foi testada nos seguintes breakpoints:

- **Desktop**: 1200px+
- **Tablet**: 768px - 1199px
- **Mobile**: 320px - 767px

## ⚡ Funcionalidades JavaScript

- **Navegação Suave**: Scroll suave entre seções
- **Menu Mobile**: Menu hambúrguer responsivo
- **Header Dinâmico**: Muda aparência no scroll
- **Animações de Entrada**: Elementos aparecem conforme scroll
- **Contadores Animados**: Estatísticas com animação
- **Formulário de Contato**: Validação e feedback
- **Notificações**: Sistema de alertas visuais
- **Efeito Parallax**: Movimento suave dos elementos
- **Efeito de Digitação**: Animação no título principal

## 🔧 Personalização

Para personalizar a landing page:

1. **Cores**: Modifique as variáveis CSS no arquivo `styles.css`
2. **Conteúdo**: Edite os textos no arquivo `index.html`
3. **Funcionalidades**: Adicione ou modifique funções no `script.js`
4. **Imagens**: Substitua os placeholders por imagens reais
